# 魔方一步步

多尺寸魔方填色和逐步还原工具。X、Y、Z 分别为左右、上下、前后方向格数，每项可填写 1–7，支持正方体和长方体。六面展开图和三维预览随尺寸变化。尺寸、填色和随机打乱记录保存在当前浏览器。

“试试随机魔方”生成可还原状态；“随机涂黑”按指定百分比随机选取已填、可编辑的格子并涂黑。保留其他颜色和三阶固定中心，重复点击可能增加黑格。涂黑比例支持 0–100%。应用新尺寸会重新开始。

随机打乱的长度也会随机：设最大边长为 n，长度在 max(12, 4n) 到 max(24, 8n) 之间随机取整数。七阶为 28–56 步，不再固定 24 步。页面显示实际打乱长度并随当前状态保存。还原方案长度以验证结果为准，黑色目标可能提前完成；不保证最短。连续两次随机长度可能恰好相同。

黑色是“忽略”标记：黑格随所在层一起转动，但不参与完成判断。只要其余非黑色格子都在对应中心颜色的面上，就完成还原。黑色格数不限，不能设为中心色。可用“将未填格涂黑”快速输入局部目标。

二阶、三阶支持任意合法填色求解，包括黑色忽略状态。三阶局部状态先寻找三步内的解；否则补出合法状态并求解。二阶将角块嵌入三阶角块模型求解。方案会在非黑色目标首次达成时结束，不保证最短。

其他尺寸通过保存的打乱和手动转动记录逐步还原，刷新后记录仍保留。自填颜色若与原打乱状态不相符，会尝试三步内搜索，最多 6 万次尝试；搜索失败会说明范围，不保证求解任意复杂自填状态。黑色涂画不会丢失已知打乱记录。

长方体某一旋转轴的截面不是正方形时，仅允许 180° 转动。其他截面允许 90° 和 180°。非三阶支持选择任意一层；层号从 X 左侧、Y 下侧、Z 后侧开始计数，方向从对应轴的正侧（右、上、前）观察。只有三阶固定中心，其他尺寸按六面的目标配色判断完成。

运行 `node server.cjs`，打开 http://127.0.0.1:4317 ，也可双击启动魔方助手.cmd。网页必须通过 HTTP 打开，以支持后台求解线程。

操作：点击“清空重填”，选择颜色并填写六面展开图，点击“计算还原步骤”。每次点“执行下一步”只执行一条转动，180° 作为一步。视角按钮只改变观察角度，手动层转动会清除旧方案。

X 为左右轴（右 R / 左 L），Y 为上下轴（上 U / 下 D），Z 为前后轴（前 F / 后 B）。顺逆时针以正对所转面为准。中心默认上白、下黄、前绿、后蓝、左橙、右红，可调整。无法通过合法转动还原的输入会被拒绝。

求解使用 [cube.js](https://github.com/ldez/cubejs) 的二阶段算法；第三方 MIT 许可在 dist/vendor/LICENSE。资源均随项目打包，计算无需联网。方案保证执行后还原，不承诺最少步数。

验证：`node test.cjs`。`qa.cjs` 使用本机 Playwright 和 Chrome 进行浏览器端到端验证；其中运行时路径按当前环境配置。
