# 魔方一步步

多尺寸魔方填色和逐步还原工具。X、Y、Z 分别为左右、上下、前后方向格数，每项可填写 1–4,503,599,627,370,495，支持正方体和长方体，可点“使用最大尺寸”直接应用上限。每项不超过 200 时使用原有逐格模型和六面展开图；任一项超过 200 自动使用超大尺寸按需计算模型。尺寸、填色、速度和随机打乱记录保存在当前浏览器。

超大尺寸不分配与表面积相同的数组，而是保存精确尺寸、层转动、稀疏填色和确定性的涂黑规则。查询一个格子时，用逆置换映射回原始格子，得到其精确颜色。使用 BigInt 计算表面格数 2(XY+XZ+YZ)，坐标使用安全整数；数量在转换为浮点数前先精确解析，拒绝会被舍入的非整数和越界输入。上限取 floor(Number.MAX_SAFE_INTEGER / 2)，为坐标公式 2i−n+1 留出精度空间。

超大模式的整体三维图是有明确标记的抽样预览，未抽样到的层仍有精确记录，不能按抽样图判断是否已还原。局部视图每次最多显示 12×12 个精确格子，可按行列访问整个面（包括最大尺寸的最后一格），点击或输入局部颜色、执行任意层转动。支持同轴并行、上一组/下一组、运行/暂停、速度和转动动画、运行中精确重置。随机长度随阶数增长，最终限制在 5000–10000 步之间随机取数，避免与天文数量的阶数线性增长；转动记录容量 20000 条，单独填色最多 100000 格，随机涂黑最多保存 100 次规则。超大模式按概率随机涂黑，不宣称精确涂黑格数。它只保证已知转动记录、黑色忽略和与原目标一致的填色可还原；对不一致的手动颜色会明确拒绝，不能保证任意巨大自填状态求解。整体预览、保存数据和还原不枚举全部格子。

“试试随机魔方”生成可还原状态；“随机涂黑”按指定百分比随机选取已填格子并涂黑，三阶中心格也可选中。保留其他颜色，重复点击可能增加黑格。涂黑比例支持 0–100%。应用新尺寸会重新开始。

“全部涂黑”在页面顶部，可将六面所有格子（包括三阶中心格）设为黑色忽略，保留尺寸、目标配色和已知转动记录，清除旧还原方案。普通尺寸与超大尺寸都支持，刷新后保留。全黑目标不需要转动；也可在此基础上重新填写需要还原的少量颜色。所有尺寸的所有格子均可改色，“清空重填”也包含中心格。目标配色单独设置，修改中心贴纸不会改写还原目标。

逐格模式的随机打乱长度也会随机：设最大边长为 n，长度在 max(12, 6n) 到 max(24, 12n) 之间随机取整数。七阶为 42–84 步，百阶为 600–1200 步。页面显示实际打乱长度并随当前状态保存。还原方案长度以验证结果为准，黑色目标可能提前完成；不保证最短。连续两次随机长度可能恰好相同。

两百阶包含 240000 个表面格子，随机打乱 1200–2400 步；生成和已知打乱记录求解在后台执行。打乱及历史记录容量为 10000 步，覆盖新增尺寸范围。

黑色是“忽略”标记：黑格随所在层一起转动，但不参与完成判断。只要其余非黑色格子都在对应中心颜色的面上，就完成还原。黑色格数不限，不能设为目标中心配色。可用“将未填格涂黑”快速输入局部目标。

“手动填写颜色（输入或粘贴）”可选择六面之一，按从上到下、从左到右的顺序直接输入。支持中文颜色，以及 W 白、R 红、G 绿、Y 黄、O 橙、B 蓝、K 黑；空格、换行和常见分隔符可混用。W9 代表连续 9 个白格，K40000 可一次填写两百阶的一整个黑色面，? 代表未填格。读取当前面会按实际行列格式输出。应用时先检查字符和数量，错误输入不会修改魔方。中心格与其他格子采用相同输入规则，整体合法性由求解器检查。

二阶、三阶支持任意合法填色求解，包括黑色忽略状态。三阶可直接填写中心、通过文本导入任意中心颜色，并手动转动第 1/2/3 层。局部状态先在全部层中寻找三步内的解；否则枚举 24 种可达中心朝向，用中间层前缀对齐中心，再补出合法状态并通过二阶段算法求解。每个方案都在原始输入上验证，支持无历史记录的合法中间层打乱及中心涂黑。不能匹配目标配色的中心排列会明确报错，不会静默修改填色或目标。二阶将角块嵌入三阶角块模型求解。方案会在非黑色目标首次达成时结束，不保证最短。

其他尺寸先按色块置换进行有下界剪枝的有限深度搜索，搜索直接基于当前非黑色状态。未找到简单解时，使用保存的打乱记录构造一个解，再用同轴不同层的交换律、同层转角模 4 合并、抵消以及重复颜色状态消除来化简，删除对当前颜色状态没有影响的转动。高阶转动只保存受影响色块的稀疏置换，避免为每一步复制完整置换表。每个返回方案都从当前状态正向执行验证。界面区分“置换搜索”和“置换化简（使用打乱记录）”，不承诺高阶复杂自填状态总能求解，也不承诺最短。

“运行”连续逐步执行，可随时暂停。速度可设 0.5–120 步/秒，可通过滑块或手动数字输入调整，新速度从下一步生效。关闭动画时按时间累计执行步骤，合并重复绘制以提高速度，仍按顺序执行每条转动，手动“下一步”始终只执行一步；实际速度受设备性能影响。暂停时当前转动完成即停止。“重置本次运行”恢复本次求解前的完整填色、黑色位置和打乱记录，保留还原方案以便重播；转动中重置会在本步结束后恢复。重新填色或生成随机魔方会清除旧方案。

可选“并行转动／还原”，也可点击“计算并行还原”直接开启并求解。同一连续段中绕同一个 X、Y 或 Z 轴的不同层相互独立，可以同时转动；同层转角按模 4 合并或抵消，保留不同轴之间的先后关系。后台会正向验证并行方案。开启后，上一步整组撤销、下一步整组执行、运行逐组播放，速度单位变为组/秒，并分别显示组数、实际层转动次数及原方案步数。三维视图与展开图同步显示组内各层的独立方向和角度。暂停后可切换模式，保留当前魔方状态，已执行和未执行部分分别重新分组；重置仍恢复原始填色和黑格。选项会保存。

“显示转动动画”控制单步、手动转动和连续运行的动画，设置会保存。默认遵循系统减少动态效果的偏好，也可以手动开启。大尺寸画布逐帧旋转指定层，按当前速度完成 90° 或 180° 转动；绘制网格会在该层边界处拆分，确保百阶的细薄内层也能单独显示。调整视角、暂停、重置与动画可以同时使用；关闭动画从下一步生效。

展开图也显示运行过程，使用与三维转动相同的动画时钟。紫色高亮本步受影响的区域，色块沿面内旋转弧线或跨面流向示意移动，终点严格对应实际色块置换。展开图旁的运行/暂停、下一步、重置与原控制器共享同一份状态。暂停和转动中重置不会提前清除尚在进行的展开图动画。大尺寸自动跟随受影响的面：整面转动显示位图旋转，跨面交换显示格子的流入/流出。关闭动画时保留高速度批量执行，并同步显示结果和已执行步数。

最大边超过 12 时使用单面填色画布，可切换六个面、缩放和滚动，也可输入行列精确填色。三维预览按真实行列生成颜色纹理，再通过透视网格绘制，边缘和中间格子使用相同的几何比例；不再把抽样后剩余的格子单独画成窄条。高阶缩小显示时使用纹理过滤并平滑细网格，避免密集网格的干扰纹；高分辨率屏幕按设备像素比例绘制。大尺寸随机生成在后台线程执行；100×100×100 包含 60000 个表面格子。

长方体某一旋转轴的截面不是正方形时，仅允许 180° 转动。其他截面允许 90° 和 180°。所有尺寸均可选择任意一层；层号从 X 左侧、Y 下侧、Z 后侧开始计数，方向从对应轴的正侧（右、上、前）观察。三阶的中间层会移动中心贴纸，各尺寸都按单独设置的六面目标配色判断完成。

运行 `node server.cjs`，打开 http://127.0.0.1:4317 ，也可双击启动魔方助手.cmd。网页必须通过 HTTP 打开，以支持后台求解线程。

操作：点击“清空重填”，选择颜色并填写六面展开图，点击“计算还原步骤”。每次点“执行下一步”只执行一条转动，180° 作为一步。视角按钮只改变观察角度，手动层转动会清除旧方案。

X 为左右轴（右 R / 左 L），Y 为上下轴（上 U / 下 D），Z 为前后轴（前 F / 后 B）。顺逆时针以正对所转面为准。中心默认上白、下黄、前绿、后蓝、左橙、右红，可调整。无法通过合法转动还原的输入会被拒绝。

求解使用 [cube.js](https://github.com/ldez/cubejs) 的二阶段算法；第三方 MIT 许可在 dist/vendor/LICENSE。资源均随项目打包，计算无需联网。方案保证执行后还原，不承诺最少步数。

验证：`node test.cjs`。`qa.cjs` 验证原有三阶、黑色和尺寸功能；`qa-run.cjs` 验证自动运行、暂停、速度、精确重置、无打乱记录的高阶置换搜索及百阶随机状态。浏览器脚本使用本机 Playwright 和 Chrome，其中运行时路径按当前环境配置。

动画验证：`node test-animation.cjs` 核对全部轴、方向和各层的动画终点与精确置换，并检查百阶抽样边界；`qa-animation.cjs` 验证真实中间帧、调速、运行、转动中重置、开关保存和百阶内层动画。

扩展验证：`node test-expanded.cjs` 验证颜色文本解析、非法输入、两百阶尺寸和超过 2000 步的历史；`qa-expanded.cjs` 验证六面手动导入、速度实测、高速暂停重置、两百阶随机状态和完整方案验证。

展开图验证：`node test-net-motion.cjs` 校验转移终点、受影响面和含黑格状态；`qa-net-motion.cjs` 检查实际中间帧、与 DOM/画布三维视图的同步、展开图控制器、暂停撤回、转动中重置、受影响面跟随及两百阶动画。

边缘验证：`node test-render-edges.cjs` 校验每个格子的覆盖、纹理与几何比例、边界转动和投影；`qa-render-edges.cjs` 检查首尾颜色、二十五阶实际列宽和高分辨率渲染。`qa-edge-gallery.cjs` 可输出多阶对比图。

并行验证：`node test-parallel.cjs` 校验同轴交换、合并抵消、不跨轴重排、整组逆变换、黑格以及两百阶多层几何；`qa-parallel.cjs` 验证实际后台分组、多层 DOM/画布动画、展开图同步、整组上一步/下一步、保留状态切换模式、运行中重置、高速还原与手机布局。

超大尺寸验证：`node test-huge.cjs` 将按需颜色与原有逐格模型逐格对照，覆盖随机转动、涂黑、整组还原和逆转；验证最大坐标、BigInt 表面计数和非法数量。`qa-huge.cjs` 验证一键应用最大值、最后一格填色与刷新恢复、五千至一万步实际随机生成和验证、并行动画/撤销/运行/重置、长方体限制、手机布局以及返回普通模式。

中心编辑验证：`qa-centers.cjs` 验证中心点击、文本填写、刷新保留且不改目标配色、中间层的三个轴、独立求解十二组无历史混合层状态（包括黑色中心）、精确重置、不可达中心目标报错以及三阶/七阶一致的随机涂黑和手机布局。
